## 快速上手

新建一篇文章只需两步：

1. 在 `posts/` 目录新建一个 `.md` 文件（文件名建议用英文，如 `data-structure-1.md`）
2. 在 `posts.json` 的数组里加一条记录：

```json
{
  "file": "data-structure-1.md",
  "title": "数据结构笔记（一）：单链表",
  "date": "2026-09-01",
  "tags": ["自考", "数据结构"],
  "summary": "一句话摘要，会显示在首页卡片上。"
}
```

首页会自动按日期倒序排列，点击标签可以筛选。**正文不用写一级标题**（`#`），文章页的大标题来自 `posts.json` 里的 `title`，正文从 `##` 开始写。

## 支持的语法

### 文字样式

**加粗**、*斜体*、~~删除线~~、`行内代码`，当然还有 [链接](https://github.com)。

### 列表

- 无序列表项
- 另一项
  - 缩进两格就是二级
1. 有序列表
2. 第二项

任务列表（可以当打卡用）：

- [x] 已完成任务
- [ ] 未完成任务

### 引用

> 引用块，适合放重点提示或者自己的感悟。

### 代码块

三个反引号开头并标注语言：

```c
#include <stdio.h>

int main(void) {
    printf("Hello, 自考!\n");
    return 0;
}
```

## 图片怎么放

把图片放进 `posts/` 目录，然后在文章里这样引用：

```markdown
![图片说明](posts/example.png)
```

## 站名想改？

打开 `assets/main.js`，最顶上的 `SITE` 配置里改 `title`、`subtitle`、`description`、`footer` 四个字段即可，两个页面都会跟着变。
