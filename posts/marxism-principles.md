把《马克思主义基本原理》的思维导图写成一篇复习文章

> 一句话总纲：导论讲"马克思主义是什么"，哲学讲"怎么认识世界和改造世界"，
> 政治经济学讲"资本主义怎么运转"，科学社会主义讲"接下来往哪走"。

## 一、导论：马克思主义是什么

### 六个"是"，把内涵背死

- 马克思主义是由**马克思和恩格斯**创立并为后继者不断发展的**科学理论体系**（创立者）
- 是关于**自然、社会和人类思维发展一般规律**的学说（内容）
- 是关于**社会主义必然代替资本主义、最终实现共产主义**的学说（目的）
- 是关于**无产阶级解放、全人类解放和每个人自由而全面发展**的学说（立场）
- 是**无产阶级政党和社会主义国家的指导思想**（地位）
- 是指引人民**创造美好生活的行动指南**（意义作用）

再往下拆，三个组成部分：**马克思主义哲学、马克思主义政治经济学、科学社会主义**，本文的结构基本就是沿着这三块走的。

### 立场、观点、方法

- **基本立场**：观察、分析和解决问题的根本立足点和出发点——以人民为中心，一切为了人民、一切依靠人民。
- **基本观点**：对自然、社会和人类思维发展一般规律的科学认识（这是它独有的），是对人类思想成果和社会实践经验的科学总结。
- **基本方法**：建立在辩证唯物主义和历史唯物主义基础上，主要包括实事求是、辩证分析、社会基本矛盾和主要矛盾分析、历史分析、阶级分析、群众路线等方法。

### 诞生：1848 年 2 月，《共产党宣言》

组织线索是"正义者同盟 → 共产主义者同盟"，**1848 年 2 月《共产党宣言》发表，标志马克思主义公开问世**。

它不是凭空出现的，要记三个条件：

1. **社会根源**：资本主义生产方式当时在西欧已有相当发展；
2. **阶级基础**：无产阶级作为独立的政治力量登上历史舞台；
3. **思想渊源**：**德国古典哲学、英国古典政治经济学、英法空想社会主义**——三大来源正好对应后来的三个组成部分。

发展线索一条线串下来：经典马克思主义 → **列宁主义** → **毛泽东思想** → **中国特色社会主义理论体系**（邓小平理论、"三个代表"重要思想、科学发展观、习近平新时代中国特色社会主义思想）。

### 四个基本特征

**科学性、人民性、实践性、发展性**。其中**实践性是马克思主义理论区别于其他理论的根本特征**——这一点到认识论部分还会反复出现。

## 二、辩证唯物论：世界统一于物质

### 哲学基本问题的两个侧面

| 侧面 | 追问的是什么 | 由此划出的阵营 |
| --- | --- | --- |
| 第一性 | 物质和意识谁先谁后 | 唯物主义（物先）/ 唯心主义（意识先），二元论摇摆其间 |
| 同一性 | 意识能不能认识客观世界 | 可知论 / 不可知论 |

### 物质：恩格斯到列宁

恩格斯说："物、物质无非是各种物的总和，而这个概念就是从这一总和中抽象出来的。"

列宁作出了全面的科学规定，三句话：

1. 物质是标志**客观实在**的哲学范畴，这种客观实在是人通过感官感知的；
2. 它**不依赖于我们的感觉而存在**；
3. 它**为我们的感觉所复写、摄影、反映**。

> 记忆点：我感没感知到它，它都在那里，不增不减；感知到的东西会映射到我们的脑海。

### 运动、静止与时空

- **物质与运动**不可分割：运动是物质的存在方式和根本属性。答题模板固定为"A 是 B 的 A，B 是 A 的 B"——运动是物质的运动，物质是运动着的物质。
  > 割裂开就出错：只谈物质不谈运动，是形而上学的唯物主义；只谈运动不谈物质，是唯心主义。
- **运动与静止**是对立统一关系：运动的**绝对性**体现变动性、无条件性；相对静止是物质运动在一定条件下的稳定状态，包括**空间位置暂时不变**和**基本性质暂时不变**两种特殊状态。二者互相依赖、互相渗透、互相包含——动中有静，静中有动。
- **时空**：时间指物质运动的持续性、顺序性，特点是**一维性**；空间指物质运动的广延性、伸张性，特点是**三维性**。时间和空间是运动着的物质的基本存在形式。

### 意识：起源与能动作用

意识是**人脑的机能和属性，是客观世界的主观映象**。起源说两句话：

- 一方面，意识是**自然界长期发展**的产物；
- 另一方面，意识也是**社会历史发展**的产物——社会实践特别是**劳动**，在意识的产生和发展中起决定性作用。

意识对物质有能动的反作用，四条：具有**目的性和计划性**、具有**创造性**、能**指导实践改造客观世界**、能**调控人的行为和生理活动**。

物质与意识的辩证关系，按"区别 + 联系"来答：

- 区别：物质是本源、意识是派生；物质不是意识、意识不是物质；二者不能互相代替。
- 联系：物质可以转化为意识，意识也可以转化为物质；意识对物质既有依赖性又有相对独立性；物质决定意识，意识反作用于物质。

**主观能动性与客观规律性**也是辩证统一的：尊重客观规律，才能正确发挥主观能动性；充分发挥主观能动性，才能正确认识和把握客观规律。

### 意识与人工智能（理解即可）

人工智能不可能取代或超越人类智能，四个理由：

1. 它只是对人类**理性智能**的模拟和拓展，不具备情感、信念、意志等人类意识形式；
2. **社会性**是人的意识固有的本质属性，人工智能不可能真正具备人类的社会属性；
3. 人的自然语言是思维的外壳和意识的现实形式，人工智能难以完全具备**理解自然语言真实意义**的能力；
4. 人工智能只能获得可以约化为数字信号的内容，而人脑中总有许多东西是**无法被约化**的。

### 世界的物质统一性

- 一方面，物质分化为**自然界和人类社会**——人类社会是最高级的物质存在形态，但二者不是截然分开的，而是交叉重叠、互相作用的；
- 另一方面，世界分化为**客观世界和主观世界**——主观世界从客观世界中分化出来，有相对独立性，但它不是独立存在的实体，归根到底从属于客观世界。

到这里，辩证唯物论的结论就立住了：**世界统一于物质**。

## 三、唯物辩证法：联系和发展

### 两大总特征：普遍联系、变化发展

**联系**有四个性质：

1. **客观性**——联系是客观的，但并非不可改变；
2. **普遍性**——三层含义：任何事物内部的不同部分和要素之间相互联系；任何事物都不能孤立存在；整个世界是相互联系的统一整体，每一事物都是其中的一个成分或环节；
3. **多样性**——主要方式有内部联系与外部联系、直接联系与间接联系、必然联系与偶然联系、本质联系与非本质联系；
4. **条件性**——条件对事物发展起支持或制约作用；条件可以改变，经过努力能把不利条件转化为有利条件；但改变和创造条件不是任意的，要尊重客观规律。

**发展**要抓三层：

- 内涵：发展是前进的、上升的运动（**并非所有运动都是发展**）；
- 实质：**新事物的产生和旧事物的灭亡**——新事物指合乎历史前进方向、具有远大前途的东西，旧事物指丧失历史必然性、日趋灭亡的东西；
- 过程性：恩格斯说，"世界不是既成事物的集合体，而是**过程的集合体**"。

### 三大规律之一：对立统一规律（矛盾）

**对立统一规律是唯物辩证法的实质与核心**——因为它揭示了事物普遍联系的根本内容和变化发展的内在动力，从根本上回答了事物为什么会发展。

矛盾的两个基本属性：

- **斗争性（对立属性）**：矛盾着的对立面之间相互排斥、相互分离的性质和趋势。斗争性质有对抗性（激烈）和非对抗性（缓和）之分。
- **同一性（统一属性）**：矛盾双方相互依存、相互贯通的性质和趋势——相互依存，互为存在前提；相互贯通，在一定条件下相互转化。

两者在发展中的作用分开记：

- **同一性的作用**：矛盾双方可以利用对方的发展使自己得到发展；可以互相吸收有利于自身的因素而得到发展；可以向着彼此的对立面转化而得到发展，并规定着事物发展的方向。
- **斗争性的作用**：斗争促进矛盾双方力量对比变化，此消彼长，造成事物的**量变**；斗争促使矛盾双方地位或性质发生变化，实现事物的**质变**。

**普遍性与特殊性**：

- 普遍性一句话：矛盾无处不在、无时不有。
- 特殊性是指各具体事物的矛盾及每一矛盾的各个方面，在发展的不同阶段上各有其特点——不同事物的矛盾各有特点；同一事物的矛盾在不同发展过程和阶段各有不同特点；构成事物的诸多矛盾以及每一矛盾的不同方面，各有不同的性质、地位和作用。

**矛盾发展的不平衡性**：矛盾有根本矛盾和非根本矛盾之分；在矛盾体系中，处于支配地位、对事物发展起决定作用的是**主要矛盾**，处于服从地位、起次要作用的是**次要矛盾**。

> 导图里的例子很传神：考研期间，考研就是主要矛盾，其他一切事情都是次要矛盾。

### 三大规律之二：量变质变规律

先分清三个概念：

- **质**：一事物区别于其他事物的内在规定性。说人话——这玩意儿**是什么**。
- **量**：事物的规模、程度、速度等可以用数量关系表示的规定性。说人话——这玩意儿**有多少**。
- **度**：质和量的统一在度中得到体现。度是保持事物质的稳定性的数量界限，度的两端叫**关节点（临界点）**，一旦超出，此物就转化为他物。

> 度这个范畴给我们的启示：认识和处理问题要**掌握适度原则**。

量变和质变的辩证关系：量变是质变的**必要准备**，没有量变的积累质变就不会发生；质变是量变的**必然结果**，并为新的量变开辟道路；量变质变还**相互渗透**——总的量变过程中有阶段性和局部性的部分质变，质变过程中也有旧质在量上的收缩和新质在量上的扩张。

### 三大规律之三：否定之否定规律

四个要点：

1. 否定是事物的**自我否定**，是事物内部矛盾运动的结果；
2. 否定是事物**发展的环节**，是旧事物向新事物的转变、从旧质到新质的飞跃；
3. 否定是新旧事物**联系的环节**，新事物孕育产生于旧事物，新旧事物是通过否定环节连接起来的；
4. 辩证否定的实质是**扬弃**——新事物对旧事物既批判又继承。

### 五对基本范畴（联系和发展的基本环节）

| 范畴 | 一句话关系 |
| --- | --- |
| 内容和形式 | 内容决定形式，形式反作用于内容，二者相互依赖不可分割 |
| 现象和本质 | 现象是外部的、个别的、多变的，靠感官感知；本质是内在的、一般的、稳定的，靠理性思维把握 |
| 原因和结果 | 引起某现象的是原因，被引起的是结果；原因产生结果，结果反过来影响原因 |
| 必然和偶然 | 必然是确定不移的趋势，偶然是可能出现也可能不出现、可以这样出现也可以那样出现的不确定因素 |
| 可能和现实 | 可能是潜在的、尚未实现的东西，现实是互相联系着的实际存在的事物的综合 |

几个容易考的细节：

- 现象有**真相和假象**之分，但**假象也是本质的表现**；假象和错觉不是一回事。
- 原因和结果的区分既是确定的又是不确定的，因果的关系是**复杂多样**的：一因多果、同因异果、一果多因、异因同果、多因多果、复合因果。

### 客观辩证法与主观辩证法

客观辩证法指客观事物以相互作用、相互联系的方式呈现出的辩证运动和发展；主观辩证法指人类认识和思维运动的辩证法，即以概念为思维细胞的辩证思维。二者是统一的。

## 四、认识论：实践、真理与价值

### 实践：马克思主义的招牌概念

马克思在《关于费尔巴哈的提纲》中集中阐述了科学的实践观：实践是**感性的、对象性的物质活动**，"全部社会生活在本质上是实践的"。实践的基本特征三条：

- **直接现实性**——把脑中的"物"变成现实的物；
- **自觉能动性**——实践受意识指导；
- **社会历史性**——不同历史阶段的人，实践是不一样的。

实践的基本结构是"**主体—客体—中介**"：

- **主体**：从事现实社会实践活动的、具有一定主体能力的人。主体能力包括自然能力和精神能力，精神能力又分知识性因素（首要能力）和非知识性因素；
- **客体**：实践活动所指向的对象。注意：客观事物只有被**纳入主体实践活动的范围之内**、与主体相互作用，才成为现实的实践客体。客体可按不同角度分为自然客体/人工客体、自然客体/社会客体、物质性客体/精神性客体等；
- **中介**：各种形式的工具手段及运用操作它们的程序和方法，分为两个子系统——物质性工具系统（肢体延长、感官延伸、体能放大）和语言符号工具系统。

实践的形式有三种基本类型：**物质生产实践**（最基本的实践活动，构成全部社会生活的基础）、社会政治实践、科学文化实践。从这三种基本形式中派生出的**虚拟实践**具有相对独立性，不属于基本实践类型。

### 实践对认识的决定作用：四个"是"

实践的观点是辩证唯物主义认识论**第一的和基本的观点**：

1. 实践是认识的**来源**（起决定作用的一条）；
2. 实践是认识发展的**动力**；
3. 实践是认识的**目的**；
4. 实践是检验认识真理性的**唯一标准**。

> 马克思："人的思维是否具有客观的真理性，这不是一个理论的问题，而是一个实践的问题。"

### 认识的本质与过程

**本质**上分两条路线：

- 唯心主义**先验论**：从思想到感觉、到物——错误；
- 唯物主义**反映论**：从物到感觉和思想——正确。其中辩证唯物主义是**能动反映论**，旧唯物主义是**直观反映论**。

**过程**上要经历两次飞跃：

1. **第一次飞跃**：从实践到认识，即从**感性认识**（认识的低级阶段，包括感觉、知觉、表象三种形式，特点是直接性和具体性）上升到**理性认识**（认识的高级阶段，包括概念、判断、推理以及假说和理论等形式，特点是间接性和抽象性）；
2. **第二次飞跃**：从认识到实践——这是认识过程中**更为重要**的一次飞跃。

认识过程中还有两类因素：**理性因素**起指导、解释和预见作用；**非理性因素**起激活和驱动作用。

认识规律两条：**反复性**——对复杂事物的认识要经过多次反复才能完成，客观上事物的本质暴露有一个过程，主观上人的认识能力有一个提高的过程；**无限性**——"实践、认识、再实践、再认识"循环往复以至无穷。总起来说，**实践和认识是具体的历史的统一**。

### 真理及其特性

真理是人们对客观事物及其规律的**正确反映**：

- **客观性**：真理的内容是客观的，检验真理的标准也是客观的——承认真理的客观性，就是坚持真理问题上的唯物主义；客观性决定了**一元性**，即同一条件下对特定认识客体的真理性认识只有一个。
- **绝对性与相对性**：绝对性指真理主客观统一的确定性和发展的无限性——任何真理都包含同客观对象相符合的客观内容，都同谬误有原则界限；人类认识按其本性能够正确认识无限发展的物质世界。相对性指一定条件下人们的正确认识总是有限的、不完善的——从广度上看，任何真理都只是对客观世界某一部分、某一阶段的正确认识，有待拓展；从深度上看，只是对客观对象一定方面、一定层次、一定程度的正确认识，有待深化。
- **真理与谬误**：二者互相对立，但在探索真理的过程中谬误难免；同时它们的对立又是相对的，互相依存、互相转化。

**检验标准**：实践是主观见之于客观的物质活动，是检验真理的唯一标准——但这**并不排斥逻辑证明的作用**。实践标准既有**确定性（唯一性）**——经过实践检验的认识都具有不可推翻的性质，又有**不确定性**——一定历史阶段的具体实践有局限性，检验一个真理是个过程，不是一次完成的。

### 价值以及真理与价值的统一

价值是反映主体和客体之间**意义关系**的哲学范畴，基本特性四个：**主体性、客观性、多维性、社会历史性**。

价值评价的主要特点：以主客体之间的价值关系为认识对象；评价结果与评价主体直接相关；评价结果正确与否，依赖于对客体状况和主体需要的认识；价值评价有科学和非科学之分。

**任何成功的实践都是真理尺度和价值尺度的统一**，是合规律性和合目的性的统一：价值尺度必须以真理为前提，而人类自身的内在尺度又推动着人们不断发现新的真理。

### 从必然走向自由

哲学上的自由是表示人的活动状态的范畴。**自由是对必然的认识和对客观世界的改造**——认识必然、争取自由，是人类认识世界和改造世界的根本目标。

## 五、唯物史观：社会历史的规律

### 唯物史观与唯心史观的对立

社会历史观的基本问题是**社会存在和社会意识的关系问题**。马克思之前的唯心史观有两大缺陷：

1. 至多考察了人们活动的思想动机，没有进一步追究思想动机背后的**物质动因和经济根源**；
2. 只看到**个人**在历史上的作用，忽视了**人民群众**创造历史的决定作用。

马克思科学地解决了社会存在和社会意识的关系问题，发现了人类社会发展的客观规律，创立了唯物史观。

### 社会存在与社会意识

**社会存在**是社会生活的物质方面，包括三个要素：

- 自然地理环境和人口因素——人类社会生存和发展的必要条件；
- **物质生产方式**——劳动者和劳动资料结合的特殊方式，是生产力和生产关系的统一体，集中体现人类社会的物质性。**生产方式是社会历史发展的决定力量**。

**社会意识**是社会生活的精神方面：

- 按主体分：个体意识和群体意识；
- 按层次分：**社会心理**（低层次、自发的、不系统不定型的、以感性为主）与**社会意识形态**（高层次、自觉的、系统的、相对稳定的，包括政治法律思想、道德、艺术、宗教、哲学、科学等）；
- 意识形态又有之分：**意识形态**是反映一定经济关系、政治关系以及一定阶级和社会集团利益要求的思想体系；**非意识形态**则如自然科学，不反映阶级利益。

### 两对社会基本矛盾（两条规律）

**第一对：生产力与生产关系。**

生产力三要素：

1. **劳动资料**（劳动手段）——其中最重要的是**生产工具**，它是生产力发展水平的客观尺度，也是区分社会经济时代的客观依据；
2. **劳动对象**——劳动资料和劳动对象合称**生产资料**；
3. **劳动者**——生产力中**最活跃**的因素，生产资料和劳动者相结合才变为现实生产力；现代生产中脑力劳动者的质量和数量日益具有决定性意义。

生产关系是人们在物质生产过程中形成的、不以人的意志为转移的**经济关系**，是社会关系中最基本的关系。其中**生产资料所有制**是最基本的、决定性的方面，构成全部生产关系的基础，是区分不同生产方式、判定社会经济结构性质的客观依据。

规律：**生产关系一定要适合生产力状况**——这是人类社会发展的基本规律，表现为"基本适合 → 基本不适合 → 新的基础上的基本适合"。

**第二对：经济基础与上层建筑。**

经济基础是由社会一定发展阶段的生产力所决定的**生产关系的总和**（大体等于生产关系）。上层建筑是建立在一定经济基础之上的意识形态以及相应的制度、组织和设施，分两块：

- **政治上层建筑**：在一定的意识形态指导下建立起来，是统治阶级意志的体现，包括国家政权、政党、军队、警察、法庭、监狱等——**核心是国家政权**，国家的实质是一个阶级统治另一个阶级的工具；
- **观念（思想）上层建筑**：政治法律思想、道德、艺术、宗教、哲学等意识形态，为政治上层建筑提供理论依据。

新建立的上层建筑总有不完善之处；上层建筑一旦形成就有脱离经济基础的倾向；经济基础的变化也不会立刻在上层建筑中得到反映——这些矛盾积累到尖锐化，就要求变革。

### 交往与世界历史

交往是一定历史条件下，个人、群体、阶级、民族、国家之间在物质和精神上相互来往、相互作用的活动，是生产关系的具体化。交往与生产力发展相伴随，其作用可记四个"促进"：促进生产力发展、促进社会关系进步、促进文化的发展与传播、促进人的全面发展。**生产方式的发展变革是世界历史形成和发展的基础，普遍交往是世界历史的基本特征**。

### 社会形态及其更替

社会形态是同生产力发展一定阶段相适应的**经济基础与上层建筑的统一体**。更替有三个特点：**统一性和多样性、必然性和选择性、前进性和曲折性**。

社会进步表现在两个方面：社会形态从低级到高级的发展，以及同一社会形态内部的发展。人的发展最根本的是**自由程度的提高**，从低级到高级分三个阶段：**人的依赖关系占统治地位的阶段 → 以物的依赖关系为基础的人的独立性阶段 → 自由个性阶段**。

### 社会历史发展的动力

五大动力，地位要分清：

1. **社会基本矛盾**——历史发展的**根本动力**，是一切历史冲突的根源，决定着其他社会矛盾的存在和发展；
2. 阶级斗争和社会革命；
3. 改革；
4. 科学技术；
5. 文化。

### 人民群众与个人在历史上的作用

**人民群众创造历史是唯物史观的观点；英雄创造历史是唯心史观的观点。** 唯物史观考察历史创造者的原则：立足于现实的人及其本质（马克思："人的本质不是单个人所固有的抽象物，在其现实性上，它是一切社会关系的总和"）；立足于整体的社会历史过程；从社会历史发展的必然性入手；从人与历史关系的不同层次上考察。

**人民群众是一个历史范畴**：从质上说，指一切对社会历史发展起推动作用的人们；从量上说，指社会人口的绝大多数。

杰出人物是历史人物中对推动历史发展作出重要贡献或起重要作用的人。但不管什么样的历史人物，其作用都要受到社会发展客观规律的制约，**不能决定和改变历史发展的总进程和总方向**；任何历史人物的出现都体现了必然性和偶然性的统一。评价历史人物要坚持**历史分析方法**和**阶级分析方法**。

最后一条关系链：群众是划分为阶级的，阶级通常是由政党领导的，政党是由领袖来主持的。

## 六、政治经济学：商品、价值与剩余价值

### 商品经济与商品二因素

商品经济是以交换为目的而进行生产的经济形式，产生的历史条件有两个：**社会分工的出现**；**生产资料和劳动产品属于不同的所有者**。

商品是用来交换的、能满足人们某种需要的劳动产品，具有**使用价值和价值**两个因素，是二者的矛盾统一体：

- **使用价值**：能满足人们某种需要的属性，即有用性，反映人与自然的物质关系，是商品的**自然属性**，是一切劳动产品共有的属性；使用价值构成社会财富的物质内容，并且是**交换价值的物质承担者**；
- **价值**：凝结在商品中的**无差别的一般人类劳动**，即人类脑力和体力的耗费，是商品**特有的社会属性**。决定商品交换比例的不是使用价值，而是价值。

生产商品的劳动具有**二重性**：**具体劳动**是生产一定使用价值的具体形式的劳动（有用劳动）；**抽象劳动**是撇开一切具体形式的无差别的一般人类劳动。前者生产使用价值，后者形成价值。

### 价值量：社会必要劳动时间

决定商品价值量的不是个别劳动时间，而是**社会必要劳动时间**——现有的社会正常生产条件下、在社会平均的劳动熟练程度和劳动强度下，制造某种使用价值所需要的劳动时间。

两条关系：商品价值量与生产商品所耗费的**劳动时间成正比**，与**劳动生产率成反比**。劳动还有简单与复杂之分：简单劳动是不需要专门训练的一般人都能从事的劳动，复杂劳动是需要专门训练、具有一定文化知识和技术专长的劳动者所从事的劳动。

### 价值形式的发展与货币

价值形式经历了四个阶段：**简单的或偶然的价值形式 → 总和的或扩大的价值形式 → 一般的价值形式 → 货币形式**。价值的终极外在化形式是货币。

货币是在长期交换过程中形成的、**固定充当一般等价物的商品**，有五种职能：

| 职能 | 要点 |
| --- | --- |
| 价值尺度 | 商品本身有价值，故可为尺度；只需**观念上的货币** |
| 流通手段 | 充当交换媒介；必须是**现实的货币**；所谓"劣币驱逐良币"就发生在这里 |
| 贮藏手段 | 退出流通、被保存起来 |
| 支付手段 | 赊购赊销、偿付结算 |
| 世界货币 | 超出一国范围发挥作用 |

货币产生后，整个商品世界分化为两极：一极是各种各样的具体商品，代表不同的使用价值；另一极是货币，只代表价值。商品内在的**使用价值和价值的矛盾**，就外化为**商品和货币的矛盾**。货币的出现有利于解决交换困难、促进商品经济发展，但并没有从根本上消除商品经济的矛盾，反而可能使矛盾扩大和加深。

### 价值规律

价值规律是商品经济的基本经济规律：**商品的价值量由生产商品的社会必要劳动时间决定，商品交换以价值量为基础，按照等价交换的原则进行**。它的表现形式是：**价格围绕价值上下波动**。

### 私有制商品经济的基本矛盾

以私有制为基础的商品经济中，**私人劳动和社会劳动的矛盾**是基本矛盾。它在资本主义制度下进一步发展为资本主义的基本矛盾——**生产资料资本主义私人占有和生产社会化之间的矛盾**。正是这一矛盾的不断运动，使资本主义最终被社会主义所替代具有了客观必然性。

### 马克思劳动价值论的意义

马克思在继承英国古典政治经济学"劳动创造价值"理论的同时，创立了**劳动二重性理论**。今天要深化四个方面的认识：对创造价值的劳动（生产性劳动）的界定；对科技人员、经营管理人员在生产和价值创造中作用的认识；对科技、知识、信息等新生产要素作用的认识；对价值创造与价值分配关系的认识。

### 从货币到资本：劳动力成为商品

资本主义经济制度的产生有两条途径：从小商品经济中分化出来；由商人和高利贷者转化而来。**资本原始积累**是用暴力手段使生产者与生产资料相分离、资本迅速集中于少数人手中的历史过程，两条途径：暴力剥夺农民的土地（获得**劳动力**）、暴力掠夺货币财富（获得**资本**）。

**劳动力成为商品**要具备两个基本条件：劳动者在法律上是**自由人**；并且"自由得一无所有"——没有任何生产资料和生活资料。

劳动力商品同任何商品一样有价值和使用价值，但它的特殊性在于：

- 价值由生产、发展、维持和延续劳动力所必需的生活资料的价值决定，包含三部分：维持**劳动者自身生存**所需的生活资料的价值；维持**劳动者家属生存**所需的生活资料的价值；劳动者**接受教育和训练**所支出的费用；
- 它的**使用价值是价值的源泉**——劳动力在消费过程（即劳动）中能创造新的价值，而且这个新价值比劳动力本身的价值更大。这就是货币转化为资本的秘密。

### 剩余价值的生产

资本主义生产过程具有**二重性**：既是生产使用价值的劳动过程，又是生产剩余价值的价值增殖过程（主要方面）。由于生产资料被资本家占有，劳动过程有两个特点：工人在资本家的监督下劳动，劳动隶属于资本家；劳动成果或产品全部归资本家所有。

雇佣工人的劳动分为两部分：**必要劳动**（再生产劳动力自身的价值）和**剩余劳动**（生产剩余价值 M）。**资本的本质不是物，而是一定社会历史形态下的生产关系。**

按资本在价值增殖中的作用不同：**不变资本（C）**是以生产资料形态存在的资本，其价值通过工人的具体劳动转移到新产品中去，转移量不会大于原有价值量；**可变资本（V）**是用来购买劳动力的那部分资本，其价值不是被转移的，而是由工人的劳动再生产出来，并且会增殖。剩余价值率即 m' = m/v。

资本家提高剥削程度的两种基本方法：

| 方法 | 内容 | 说人话 |
| --- | --- | --- |
| 绝对剩余价值 | 必要劳动时间不变，**延长工作日长度**或提高劳动强度 | 就是让你加班、加大劳动强度 |
| 相对剩余价值 | 工作日长度不变，通过**缩短必要劳动时间**相对延长剩余劳动时间 | 用技术手段提高全社会的劳动生产率 |
| 超额剩余价值 | 企业因提高劳动生产率，使商品的**个别价值低于社会价值**的差额 | 个别企业跑得快，赚到的差额 |

在自动化条件下，机器人再厉害，剩余价值的**唯一源泉仍然是雇佣工人的剩余劳动**。资本主义生产的根本目的是追求剩余价值，但客观上也促进了生产力的发展和社会进步。
